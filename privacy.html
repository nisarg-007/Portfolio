Privacy

Last reviewed 21 September 2026

This is a personal portfolio. It is a set of static files with no server of my own, no database and no user accounts.

What I collect

Nothing. There are no analytics scripts, no advertising scripts, no cookies set by this site, and no tracking pixels. You can confirm this by reading the source, which is linked in the footer.

The contact form

The form on the home page does not transmit anything to me. It validates what you typed in your own browser, then opens your email application with the text prefilled. Nothing leaves your device until you press send in your own mail client. If you never press send, I never receive it. What you type is not stored anywhere on this site.

Email you send me

If you email me, I keep that message in my mailbox so I can reply and refer back to it. I do not add your address to a mailing list and I do not pass it to anyone else.

Hosting

This site is hosted on GitHub Pages. GitHub serves the files and, like any web host, records request information such as IP address in its own logs. That processing is GitHub's, not mine, and I have no access to those logs. GitHub describes it in the GitHub Privacy Statement.

Third party requests your browser makes

Loading this page causes your browser to request fonts from Google Fonts, which means Google receives your IP address and user agent as part of that request. Links out to GitHub and LinkedIn only send data when you click them.
